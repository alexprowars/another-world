# Another World

Браузерная онлайн-RPG с развитием персонажа, пошаговыми боями, магией, профессиями и городской экономикой.

Проект находится в разработке.

## Технологии и требования

| Компонент | Версия / назначение |
| --- | --- |
| PHP | 8.5 |
| Laravel | 13.x |
| MySQL  | 8.x и выше |
| Composer | 2.x |
| Node.js | 22 LTS |
| Vue / Inertia | Vue 3, Inertia 3 |
| Laravel Reverb / Echo | WebSocket-сервер и клиент |

## Локальная установка

### 1. Получить проект и создать базу данных

```bash
git clone https://github.com/alexprowars/another-world.git
cd another-world
```

Создайте пустую базу MySQL с кодировкой `utf8mb4` и пользователя с правами на неё.

### 2. Настроить окружение

Скопируйте пример конфигурации в `.env`:

```bash
cp .env.example .env
```

Укажите в `.env` свои параметры MySQL. Значения Reverb в `.env.example` предназначены для локальной разработки. Сессии и кеш хранятся в файлах, очередь выполняется синхронно, письма записываются в лог.

### 3. Установить зависимости и заполнить базу

```bash
composer install
npm ci
php artisan key:generate
php artisan migrate --seed
php artisan storage:link
```

Миграции создают схему, а `DatabaseSeeder` загружает уровни, предметы и магазины из `database/sql`, добавляет рецепты, профессии, шахту, работы, администратора и тренировочных ботов. Отдельный импорт SQL-дампа не требуется.

В новой базе сидер создаёт персонажа `admin` с email `admin@admin.com` и паролем `password`. Повторный запуск всех сидеров добавляет ботов заново.

### 4. Запустить приложение

```bash
composer dev
```

Команда одновременно запускает HTTP-сервер Laravel, планировщик, обработчик очереди, просмотр логов Pail, Reverb на порту `8080` и Vite.

Откройте `http://127.0.0.1:8000`

## Команды разработки

| Команда | Назначение |
| --- | --- |
| `composer dev` | Запуск локального окружения |
| `npm run build` | Сборка frontend для публикации |
| `composer analyse` | PHPStan с Larastan; уровень 5, проверка `app/` |
| `php artisan lottery:draw` | Розыгрыш лотерей |
